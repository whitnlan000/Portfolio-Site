PackWeaver

A graph‑based command editor designed to help creators build Minecraft datapacks visually instead of writing raw .mcfunction files by hand. It turns complex command logic into a node graph that can be built, saved, and exported.

  • A visual programming tool
  • A datapack compiler
  • A workflow editor

Features

  • Visual node-based command builder
  • Auto-generates .mcfunction files
  • Save and load projects
  • Easy to use - no coding knowledge needed

CellForge

Cellular Automata Engine

CellForge is a programmable engine for creating cellular automata. It uses CellScript, a custom language used to create cellular automata, which are written rule by rule.

Example:

states {
Form1;
form2;
}

grid {
!form2 = !form1 if (`form2@1 <= 1 or `form2@1 > 3) end;
!form1 = !form2 if (`form2@1 == 2 or `form2@1 == 3) end;
}
